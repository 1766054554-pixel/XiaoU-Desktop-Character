# GitHub 发布清单

本清单用于首次发布和后续 Release。每次发布从未勾选状态开始，只有在本次实际完成并读回验证后才能勾选。

## 源码与测试

- [ ] Python 3.12 项目环境能够从零安装；
- [ ] 完整自动测试通过；
- [ ] Windows 与 macOS GitHub Actions 均通过；
- [ ] 当前系统的图形界面冒烟测试通过；
- [ ] Windows 与 macOS 构建产物由对应系统生成。

## 文件、授权与隐私

- [ ] `user_assets/` 除说明文件外全部被 Git 忽略；
- [ ] `.venv/`、`build/`、`dist/`、缓存和旧包元数据未进入提交；
- [ ] 公开构建不包含 `user_assets/`；
- [ ] 待提交文件不存在私人照片、源图集、联系方式、本机绝对路径、密钥或令牌；
- [ ] `NOTICE.md` 保留上游项目来源与修改范围；
- [ ] `ASSETS_LICENSE.md` 使用 CC BY 4.0 并保留小u像素素材署名；
- [ ] 执行 `git add --dry-run .` 并人工查看完整文件清单。

## 角色与交互

- [ ] 标准角色已由用户确认；
- [ ] 走路 GIF 已由用户确认；
- [ ] 动作画布、透明背景、比例、肢体和裁切检查通过；
- [ ] 右键菜单、状态面板、说话开关、拖动、缩放与退出可用；
- [ ] macOS 跨桌面空间显示与 Windows 置顶行为分别完成验证。

## GitHub 与 Release

- [ ] 创建并推送 `main` 分支；
- [ ] 远程 Actions 全部通过；
- [ ] 创建与 `pyproject.toml` 一致的版本标签；
- [ ] Release 只包含公开构建和必要说明；
- [ ] 从 Release 重新下载、校验、解压并启动对应平台产物。
