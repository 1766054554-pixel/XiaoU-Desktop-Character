# Quality Checklist

- Character candidate was personally approved by the user.
- Walk GIF was personally approved by the user.
- Every runtime image is RGBA, 560x500, visible, and padded from all four edges.
- Identity, hair, skin tone, proportions, and main outfit stay consistent.
- No extra head, hand, finger, arm, or leg is visible.
- Sit, sleep, drag, prop, and corgi states do not jump in scale.
- Walk alternates feet and does not shake or slide in place.
- Speech remains readable and can be disabled.
- The action menu, size controls, pause, hide, and exit commands work.
- macOS remains visible across desktop spaces; Windows remains topmost.
- Tests, platform smoke test, package integrity check, and privacy scan pass.
- Public Git file lists contain no source photo, selfie, source sheet, review image, backup, local absolute path, credential, or user contact detail.
